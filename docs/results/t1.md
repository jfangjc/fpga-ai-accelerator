# T1: paired paced captioning on the fast stt-full engine

Measured 2026-11-05 Australia/Sydney (board timestamps UTC November 4).
All 40 clips in the worktree's model/testset_40.txt ran on both backends,
alternating CPU/PL order by clip, in one exclusive board.lock batch. All
80 invocations exited zero. Source is b1cb4f5 plus the minimal driver recovery
fix e6b6123; package commit d51f384, harness 2525131. No RTL was changed.
Board firmware is engine 0x00010002 at 100 MHz, RUN_NETWORK available,
32 MiB TX buffer. Routed WNS +0.521 ns / WHS +0.010 ns; 68,693 LUT,
72,091 FF, 74.5 BRAM tiles, 846 DSP and 60 URAM. Deployment hashes and
UIO/IRQ map are in ../platform.md; I2 equality/recovery is in i2.md.

## Speed-up and latency interpretation

Table VII speed-up uses the separate I2 probe's 20 alternating pairs on exactly
the same INT8 [64,304] input with 300 valid frames, qnrt with four threads and
-O3 -mcpu=cortex-a53. Every pair has byte-identical logits. CPU median/p90
217.526760/217.970133 ms; PL API median/p90
103.976444/104.083392 ms. Ratio of medians
2.092077x, median paired ratio
2.093918x. The accepted standalone probe did not
overlap a board compilation; the later complete-run probe's timing is excluded
because it did. Program loading is excluded from steady-state inference.
See results/i2-network/paired-3s.csv for every timing component.

T1 app uses three inference threads and -O2 so capture/output can use core 0.
Its preview sample populations differ because CPU merges more updates; ratios
of their aggregate preview medians are not the matched-window speed-up.

Preview latency is the age of oldest newly covered audio at software framebuffer
completion, including inference queueing, output pipe and rendering. It uses
the FIFO occupancy probe during first FFT, not process start. The inherited
anchor assumes uninterrupted paced acceptance afterward; the timeline does not
export its uncertainty bracket or later FIFO continuity. This run therefore
reports the measured FIFO-anchored renderer metric, not a separately bounded
sample-to-photon latency. Physical scanout/monitor visibility, TCP reception
and durable logging are not timed. L_word is unavailable because hypothesis
word/frame timestamps are not exported; no forced-alignment-only surrogate is
reported. No new T2 30-minute soak or physical microphone/button test was run.
The known PS frontend float portability gap remains (I2 mel is bit-exact).

```sh

# Parallel monitors (complete wrapper/redirections are in tests/t1/t1_batch.sh):
sh /home/ubuntu/stt/power.sh "$n" 0.1
LC_ALL=C pidstat -h -u -p "$app_pid" 1
```

```sh
/mnt/c/Users/jfang/Documents/stt-accelerator/.venv/bin/python tests/t1/score_t1.py /mnt/c/Users/jfang/Documents/stt-accelerator build/hw/t1-board
```
