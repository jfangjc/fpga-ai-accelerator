and staged depthwise kernels, liveness buffer reuse, exact requantization,

## Native validation after reboot, 2026-11-02

Native GCC `-O3 -mcpu=cortex-a53 -std=c11 -Wall -Wextra` build now passes.
GCC rejected the inherited pointwise inline assembly because read/write operands
count twice against its 30-operand limit. Accumulators now initialize inside the
assembly with output-only early-clobber constraints (28 operands total).
The SMULL/SMLAL2/SADALP loop and exact arithmetic are retained. Native objdump
shows the pipelined byte widening loop without stack traffic inside the K loop;
requantization uses int64 SMULL, negative adjustment, SRSHL and saturating stores.

Linux flock exclusively. Top snapshots and before/after per-core CPU accounting
are recorded for every batch. Batches with >10% competing load at either check

a batch; observed tail latency is retained. No processes were stopped.
