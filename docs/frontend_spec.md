# Front-end integration contract

`stt_frontend` runs entirely on aclk=100 MHz with synchronous active-low reset.
AXI-Lite addresses are 12 bits; data is 32 bits. AW and W are buffered independently;
responses remain asserted until accepted. Writes honor WSTRB. Unknown offsets read zero.

| Offset | Register | Reset / meaning |
|---|---|---|
| 0x00 | CONTROL | 0; bit0 enable; bits2:1 source (0 mic1, 1 mic2, 2 sum, 3 injection); bit3 pace injection at 16 kHz; bit5 right I2S channel; bit6 LED; bit7 button IRQ |
| 0x04 | STATUS | bit0 IRQ, bit1 overflow, bit2 underrun, bit3 button; bits14:4 FIFO occupancy |
| 0x08 | CLEAR | W1C bits0:3 correspond to STATUS sticky flags |
| 0x0c | IRQ_PERIOD | 1; interrupt every N completed packets (0 behaves as 1) |
| 0x10 | FRAMES | completed packet count |
| 0x14 | OVERRUNS | dropped microphone samples |
| 0x18 | UNDERRUNS | reserved, zero: empty FIFO stalls rather than fabricating samples |
| 0x20 | BEAM | delay1 bits7:0, delay2 bits15:8, signed Q15 per-channel gain bits31:16 (reset 16384) |
| 0x40,0x50 | mic1, mic2 peak | absolute 18-bit peak |
| +4 | DC | signed sum divided by 65536 |
| +8,+12 | mean square | unsigned sum divided by 65536, low then high word |

Statistics accumulate over wrapping 65536-sample windows; the first sample clears
accumulators and is excluded. Read while stopped or tolerate a window boundary.
Reset clears processing history/state; disabling pauses, it does not flush the stream.
Use reset to begin an independent clip. Change sources/delays only while stopped.

## DMA packets

MM2S: one sign-extended signed 18-bit sample per 32-bit beat. Promote int16 WAV
samples by multiplying by four. TKEEP must be 15; TLAST is ignored (clip boundaries
require reset). Bulk mode accepts whenever buffering permits; paced mode spaces
accepted samples by at least 6250 clocks. Injection bypasses microphone FIFO input
selection but uses the shared 1024-entry elastic FIFO.

S2MM: 130 32-bit words (520 bytes), TLAST on word129. Word0 sequence starts at
zero; word1 signed exponent -42; words2..129 are 64 unsigned 64-bit band powers,
low word first. Float power = integer * 2^-42. Log/normalization stay on PS.
Post S2MM buffers before enabling MM2S. Invalidate receive caches after DMA;
flush transmit caches before MM2S. IRQ is level and W1C, raised after a complete
packet is accepted. Count FRAMES to detect coalescing while IRQ remains high.

## Arithmetic and framing

18-bit samples, four fractional guard bits; preemphasis 8136950/2^23;
320-point symmetric Hann Q18; 512-point unscaled radix-2 DIT FFT with signed
32-bit real/imaginary storage, Q22 twiddles and arithmetic floor shifts.
Squared magnitudes use 64 bits; Slaney area-normalized triangular filters use
Q28 weights, 96-bit accumulation, shift28 to unsigned64. Coefficient rounding
is nearest even. Intermediate shifts floor, output truncates. No dither or log.
ROMs are generated by `python model/frontend_fixed.py`: `hann_half.mem`
(160 symmetric entries), `tw_re.mem`, `tw_im.mem` (256 entries each), and
`mel_sparse.mem` (257 entries). Sparse mel words hold a 6-bit first-band index
and two unsigned Q28 weights; each bin updates at most two adjacent bands.
Read these initialization files from the RTL directory when invoking Vivado.


First frame consumes samples0..319; later frames hop160. No tail padding.
NeMo center=True uses a 320-point Hann centered in a 512-point frame with 96
zero samples on each side. Our window starts at sample0, centered at sample160;
this corresponds to a centered STFT shifted by 160 samples. The 96-sample FFT
phase shift does not affect power. NeMo's reflected leading/trailing boundary
frames are deliberately absent. Frame timestamps should name the window center.
The model/frontend.py centered API therefore cannot be compared by simply
slicing its frames: compare with a 160-sample time offset or use float_stream.

Processing takes approximately 194,600 clocks/frame plus output stalls, below
the 1M-clock budget. FFT storage is a 512x64 true dual-port BRAM with registered
reads. History is circular 512x32 BRAM; the active window is 320 samples and the
read origin advances 160 samples after each packet. No sample shifting occurs.
The band accumulator has synchronous reads and 96-bit words. FIFO and microphone
delay memories also have registered reads; the FIFO inserts a refill cycle after
each consumed sample. Packet contents and the register map are unchanged.

The shared `stt_serial_mul` computes exact unsigned 64x32 products from eight
16x16 partial products, with a registered product and accumulation on alternating
cycles. FFT signed products use magnitudes and explicit sign restoration. FFT,
power and mel operations share this unit. This deliberately retains the existing
32-bit FFT/Q22 arithmetic, avoiding additional quantization on quiet speech.
It does not implement the requested <=27-bit scaled FFT or a butterfly every
one/two clocks: four serial products are scheduled for each butterfly.

Current file boundaries are I2S, beamformer, FFT/mel scheduler, FFT RAM and serial
multiplier. AXI registers, source selection, FIFO control, statistics and button/LED
remain in `stt_frontend`; preemphasis, framing/window control and packing remain
in the scheduler. Full per-stage module decomposition is still outstanding.

Overflow bounds: preemphasis magnitude is below 2^22 for signed 18-bit input.
Even the conservative bound 320*2^22 on an FFT node is below 2^31; Q22 twiddle
rounding and floor errors leave over 800 million counts of margin. FFT products
fit signed64; squared magnitudes fit unsigned64. A mel coefficient is below 2^23,
so summing 257 full unsigned64 products is below 2^96. The golden model asserts
signed32 bounds after every butterfly; the suite includes both full-scale
endpoints, alternating endpoints, a full-scale step and full-scale random input.


## Capture and stretch I/O

Both clocks share a fractional accumulator: add 2048000 to modulus100000000
per clock and toggle BCLK on carry. Mean BCLK=1.024 MHz, WS=BCLK/64=16 kHz;
half periods alternate48/49 clocks. WS changes on falling edge; capture skips
slot bit0 and shifts bits1..24 on rising edges after two-flop input synchronization.
Upper18 bits are retained. Select the channel matching the microphone SEL pin.
See [Knowles datasheet](https://www.knowles.com/docs/default-source/model-downloads/sph0645lm4h-b-datasheet-rev-c.pdf).
Board timing/electrical validation remains necessary, including clock jitter and
microphone revision timing; the behavioural test uses falling-edge transmit data.

Beam path has per-mic DC high-pass y=x-xprev+(32604/32768)*yprev,
256-sample delay storage and common signed Q15 gain; no fractional delay.
DC feedback products now retain 64-bit intermediates and the delayed-channel sum
uses 19 bits with a 35-bit gain product, correcting the prior implicit 32-bit
multiply truncation. Final beam output wraps to signed18, as does delay history.
Delay history must warm up for 256 samples before selecting beam output.
Button uses a two-flop synchronizer and 2^20-clock stable debounce (~10.5 ms).
LED is software controlled (listening/speaking is a PS policy).

Use the named PMOD ports with rtl/kria-constraints.xdc. Connect AXI buses to PS
interconnect/DMA, irq to concat/GIC; aresetn to the aclk peripheral reset.
Simulation: WSL `make -C sim/frontend check`; defaults to the repository `.venv`
(set PYTHON to an absolute path to override). Requires NumPy, soundfile, librosa,
Torch and Verilator. Speech vectors are regenerated from `build/sim/frontend/speech`;
run `python sim/frontend/extract_speech.py` to extract clips from the dev archive.
`sim/frontend/ooc.tcl` reads the clock XDC before synthesis, sets HD.CLK_SRC,
and performs synth/opt/place/route before emitting utilization/timing reports.
