# QNW1 packed weights, version 1

Generated by `model/export.py`. All integers are little endian. Offsets are
absolute byte offsets from the start of the blob. No pointers or pickle in the
blob. The Python calibration cache is an intermediate trusted local file only.

Header is 64 bytes; unused bytes MUST be zero:

| Byte | Type | Meaning |
|---|---|---|
|0|char[4]|`QNW1`|
|4|u32|version=1|
|8|u32|header bytes=64|
|12|u32|descriptor count|
|16|u32|descriptor stride=128|
|20|u32|descriptor table offset=64|
|24|u32|total file bytes|
|28|u32|reserved=0|
|32|f32|input quantization scale, PS only|

Descriptors are 32 u32 words each. Tensor id 0 is network input; descriptor i
(zero based) produces tensor id i+1. Store intermediate valid lengths as well
as allocated T. Inputs must refer to earlier ids. All unused words are zero.

| Word | Conv (op=1) | Add (op=2) |
|---|---|---|
|0|opcode|opcode|
|1|input tensor id|first branch id|
|2|zero|second branch id|
|3|ReLU flag|ReLU flag=1|
|4|output channels|channels|
|5|input channels per group|zero|
|6|kernel taps|zero|
|7|stride|zero|
|8|dilation|zero|
|9|padding each side|zero|
|10|groups|zero|
|11|zero|zero|
|12,13|weight offset, bytes|branch0 multiplier offset, bytes|
|14,15|bias offset, bytes|branch0 shift offset, bytes|
|16,17|multiplier offset, bytes|branch1 multiplier offset, bytes|
|18,19|shift offset, bytes|branch1 shift offset, bytes|
|20..31|reserved|reserved|

Every payload array starts at a 64-byte boundary. Biases, multipliers and shifts
are signed INT32 arrays of output-channel count; shifts may be negative.
Weights are INT8, padded to output multiples of 32 and K multiples of 16.
Logical flattened K is `input_channel * kernel_taps + tap` (depthwise K is
just tap). Disk ordering is `[output_tile][K_tile][K_lane16][output_lane32]`.
Thus each K lane contains 32 consecutive output weights. Padding weights are
zero; padded output lanes are ignored. Activation frames are not packed into
the blob. Pointwise frame tiles of 16 are a runtime choice, independent of K
weight tiles. Depthwise MUST preserve channel grouping rather than interpret
the packed weights as a dense convolution.

Consumers must check magic/version, reserved fields, descriptor sizes, offsets,
array lengths and file bounds before execution. The blob has no checksum yet;
transport integrity is the caller's responsibility. JSON `layers.json` supplies
debug names and scales; neither is needed by the integer engine.

Vector manifest entries contain input(s), output, byte dtype, `[C,T]` shape and
valid frame count. Raw files are C-contiguous with time contiguous, one byte
per activation. Add vectors have two input files. The manifest is authoritative
for signedness. Vectors use the SAME length masks as whole-network execution.
